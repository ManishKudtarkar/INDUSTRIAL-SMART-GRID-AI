What users get after installing

A desktop command center for monitoring and response.

Live telemetry

Track voltage, current, temperature, harmonics, and load across substations.

AI risk scoring

Detect anomalies, classify faults, and calculate health scores in real time.

Load balancing

Shift target load away from critical substations and support self-healing recovery.

Local alerts

Show alert history in the app, with optional email, Slack, SMS, and database storage.

Deployment checklist

Use this website as the public download surface while the app remains local-first.

  1. Package the desktop app from `desktop/` with Electron Builder.
  2. Place the generated `.exe` in `landing/downloads/` or upload it to release hosting.
  3. Update the download links in `landing/index.html`.
  4. Deploy the `landing/` folder as a static website.
